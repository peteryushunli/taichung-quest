# Landing page landmark artwork

These PNGs are unchanged copies of the project's existing native pixel artwork for the ten landmarks. The landing page shows them as facades on the map detail card and gym cards, labelled as landmark art rather than gameplay. Source: `vendor/pokefirered/data/taichung/landmarks/` (first four originally copied from the `.worktrees/game-mapping` checkout). No photo reference, external URL, generated study, or native map/source mutation is included. Vite imports produce content-hashed, same-origin assets. CSS preserves hard pixels and transparency.
