# Native encounter outcome markers

This web-only slice consumes the existing verified encounter bridge, not dialogue or Pokédex flags. Contract: geometry captureBit maps to native attempts/unlocks (21 bits); unlock dominates as caught, attempt without unlock becomes spent after the active transaction, phases 1–4 at the active site stay pending. KO, ran, lost, exhausted, interrupted and storage-error terminal outcomes all fade when native says the attempt was consumed. Gameplay remains owner of those bits and persistence/ACK behavior; no native or bridge writes changed.

Local minimap: caught is a green check, spent is a faded gray cross, pending keeps its ball with a dashed outline. Existing gym progress, crops, scales, three view modes and visibility rules remain. City Map markers and tabs use the same status and accessible text; selected landmark detail spells out the outcome. Both EN/ZH supported. Browser pause retains verified progress; reconnect/unavailable/restart/import clear it; replacement saves may reduce masks. There is no new browser progress storage. Render updates skip unchanged masks to avoid repeated live-region announcements.

Validation: model regressions cover all terminal outcomes, pending phases, caught precedence, high capture bits 18–20, pause, reconnect, and replacement saves. Production components browser fixture web/tests/encounter-browser.html checks every state on both maps without moving the crop, visible check/cross paths and Chinese labels. Screenshots in artifacts/qa/2026-11-23-interface-playtest/encounter-*.jpg are clearly marked simulated native-packet UI fixtures, not native battle evidence. Actual transaction/KO persistence needs Gameplay/Main combined-ROM QA; this slice does not claim to have run a real capture battle.

Main integration: keep the v2 native encounter metadata and geometry captureBit assignments when regenerating map artifacts. Apply after the storefront commit because both touch main.ts. No pack or geometry changes in this slice; rebuild with VITE_BOULEVARD_PREVIEW=1. Main owns final ROM/pack pairing and publication.
